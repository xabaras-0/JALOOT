**JALOOT** is a curated directory of OSINT tools for investigators, analysts, researchers, and cybersecurity practitioners.

The project provides a simple static web page that groups useful resources by investigation area and highlights tools with practical badges such as **Top**, **Authenticated**, **GitHub**, and **No badge**.

> **Live site:** https://xabaras-0.github.io/JALOOT/

---

## About

**JALOOT** stands for **Just Another List of OSINT Tools**.

It is designed as a quick-reference collection for open-source intelligence workflows, including searches related to domains, IP addresses, email addresses, usernames, companies, social platforms, data leaks, malware analysis, forensics, and more.

The interface is intentionally lightweight: the project is built as a static site, so it can be hosted directly with GitHub Pages or opened locally in any modern browser.

## Features

- Curated list of OSINT, cyber-intelligence, and investigation resources

## Contributing

Contributions are welcome, especially additions, fixes, and updated links.

When suggesting a new tool, please include:

1. Tool name
2. Official URL
3. Short description 
4. Suggested category

### Suggested contribution workflow

```bash
# 1. Fork the repository
# 2. Create a new branch
git checkout -b add-new-osint-tool

# 3. Edit index.html
# 4. Commit your changes
git add index.html
git commit -m "Add new OSINT tool"

# 5. Push and open a pull request
git push origin add-new-osint-tool
```

Before opening a pull request, please verify that:

- The link is working
- The description is accurate and concise
- The resource is relevant to OSINT, investigations, or cyber-intelligence
- The tool can be used legally and ethically
- Any login/API requirement is marked as **Authenticated**

## Ethical use

JALOOT is intended for legitimate research, security analysis, journalism, investigations, and educational use.

Always follow applicable laws, platform terms of service, and organizational policies. Do not use these tools for harassment, unauthorized access, stalking, doxxing, credential abuse, or any illegal activity.
